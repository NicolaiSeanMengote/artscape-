About Artscape

Artscape is a learning and inspiration library for people in creative fields: designers, illustrators, photographers, crafters, and students. It puts fonts, color palettes, and art forms in one place so you can look things up quickly.

Everything you save stays in your own browser using Local Storage, so there is no account to create.

Built with

  • HTML, CSS, and JavaScript
  • Local Storage for saved items and suggestions
  • Google Fonts for the font previews
